# Boutique Intelligente - Vendeur WhatsApp (Marché Dantokpa)[cite: 2]

Agent conversationnel intelligent développé pour assister Afi, gérante d'une boutique de pagnes et d'accessoires au marché Dantokpa[cite: 2]. L'agent gère les demandes clients, consulte le stock en temps réel, calcule les frais de livraison, convertit les devises et prépare les commandes de manière sécurisée[cite: 2].

## Fonctionnalités & Outils (Palier 1)[cite: 4]
L'agent dispose de 5 outils métiers stricts (zéro invention de chiffres)[cite: 3, 4] :
1. `chercher_produits` : Recherche par mot-clé dans le catalogue d'Afi[cite: 3, 4].
2. `verifier_stock` : Vérifie la disponibilité exacte des stocks par référence[cite: 3, 4].
3. `frais_livraison` : Calcule les frais et délais selon la zone géographique desservie[cite: 3, 4].
4. `convertir_devise` : Convertit les prix en FCFA vers d'autres devises (EUR, USD, NGN) via une API de taux réelle[cite: 3, 4].
5. `creer_commande` : Enregistre une pré-commande en attendant la validation humaine[cite: 4].
